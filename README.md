# Project Overview
This project aims to provide users with a user-friendly platform to locate the nearest restroom facilities.

# Features
- User location detection
- Map integration to display nearby restrooms
- User reviews and ratings for facilities
- Filters for accessibility options
- Real-time updates and notifications

# Tech Stack
- Frontend: React
- Backend: Node.js with Express
- Database: MongoDB
- Map Service: Google Maps API

# Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/pandamode2019-spec/Where-Da-Potty.git
   ```
2. Change directory into the project:
   ```bash
   cd Where-Da-Potty
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the application:
   ```bash
   npm start
   ```

Visit `http://localhost:3000` to view the application.
