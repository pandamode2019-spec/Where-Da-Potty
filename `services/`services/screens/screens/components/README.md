# Components Directory

This folder contains reusable UI components that are used across multiple screens.

## Components to Build

### BathroomCard.js
Displays a bathroom in list format with name, address, and type.

### SearchBar.js
Search input component for finding bathrooms by name or location.

### MapView.js
Map display component for showing bathroom locations geographically.

### RatingComponent.js
Component for displaying and submitting bathroom ratings.

### ReviewList.js
Component for displaying user reviews and comments about bathrooms.

### AccessibilityBadge.js
Component to display accessibility features (wheelchair accessible, etc.).

## Usage

Import components in screens like this:
```javascript
import BathroomCard from '../components/BathroomCard';
